
# Emotion Detector Using IBM Watson NLP

An AI-powered emotion detection application built using **IBM Watson Natural Language Processing (NLP)** as part of the **IBM SkillsBuild** certification program.

The application analyzes user-provided text and predicts the dominant emotion expressed, demonstrating how Natural Language Processing can be integrated into real-world applications using cloud-based AI services.

---

## 📌 Project Overview

Understanding human emotions from text is an important task in Natural Language Processing (NLP). This project leverages IBM Watson's pre-trained Emotion Detection model to classify emotions present in textual input.

The application allows users to:

- Enter any text
- Analyze emotional content
- Display individual emotion scores
- Identify the dominant emotion
- Handle invalid or empty inputs gracefully

---

## 🚀 Features

- Emotion Detection using IBM Watson NLP
- Detects multiple emotions:
  - 😊 Joy
  - 😢 Sadness
  - 😠 Anger
  - 😨 Fear
  - 🤢 Disgust
- Displays confidence scores for each emotion
- Identifies the dominant emotion
- Simple and clean user interface
- Error handling for invalid text input
